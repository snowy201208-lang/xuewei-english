| 模式 | 怎么用 | 快捷键 |

| 卡片模式 | 先看单词，翻转看释义，标记「认识 / 模糊 / 不认识」 | 空格翻转 · `1` `2` `3` 标记 |

## 🚀 怎么用

### 方式一 · 手机 / 电脑浏览器直接打开

1. 下载本仓库 ZIP
2. 解压后双击 `index.html`，浏览器即可使用
3. 推荐 Chrome / Edge / Safari

### 方式二 · 部署到 GitHub Pages（手机随时访问）

**整个过程 5 分钟，无需敲任何命令。**

#### 第 1 步：新建 GitHub 仓库

1. 登录 [github.com](https://github.com)（没账号点 Sign up 注册，30 秒搞定）
2. 右上角 `+` → `New repository`
3. 填写：
   - **Repository name**：`xuewei-english`（可改名）
   - **Public** ⚠️ 必须选公开
   - 下面三个勾都不打
4. 点 `Create repository`

#### 第 2 步：上传文件

1. 在新仓库页面，点击 **`uploading an existing file`** 链接
2. 解压本仓库 ZIP，把里面**所有内容**整体拖入上传框：
   ```
   index.html
   assets/
   data/
   README.md
   .gitignore
   ```
   > ⚠️ 拖的是**目录里的文件**，不是目录本身
3. 等上传条跑完，点 `Commit changes`

#### 第 3 步：开启 Pages

1. 仓库顶栏 → **`Settings`** → 左侧栏 → **`Pages`**
2. **Source** 选 `Deploy from a branch`
3. **Branch** 选 `main` · 文件夹 `/ (root)`
4. 点 `Save`
5. 等待 1～2 分钟，页面会显示绿色横幅
   `Your site is live at https://<你的用户名>.github.io/xuewei-english/`

#### 第 4 步：手机访问

用手机浏览器打开上面的链接即可。建议：

- iOS Safari：底部分享按钮 → **添加到主屏幕**
- Android Chrome：右上角菜单 → **添加到主屏幕**

之后像 App 一样点图标就能进。
